## Standing Rules (handoff v2)

- **Whiteboard appears ONLY in the end-segment recap** (question → 3s pause → answer). Never during the main dialogue.
- **No captions burned into the video.** Word-timed `.srt` uploaded to YouTube as an optional closed-caption track.
- Every episode ends with the whiteboard recap. Non-negotiable.
- Marcia & Dave (office track) are **never** used here.
- Scripts stay format-agnostic so the still-image fallback remains available.
